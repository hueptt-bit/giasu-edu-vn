⚡ SPA Navigation Patterns

Dashboard Gia sư — switchPage(name)
// tabPages = array tên pages thông thường function switchPage(name) { tabPages.forEach(p => { document.getElementById('page-' + p).style.display = 'none'; }); // extraPages: ẩn .main, show page với position:fixed if (extraPages.includes(name)) { document.querySelector('.main').style.display = 'none'; document.getElementById('page-' + name).style.display = 'block'; } else { document.querySelector('.main').style.display = 'block'; document.getElementById('page-' + name).style.display = 'block'; } }
Dashboard Phụ huynh — switchState(name)
function switchState(name) { allPanels.forEach(p => { document.getElementById('panel-' + p).style.display = 'none'; }); document.getElementById('panel-' + name).style.display = 'block'; // update active nav item document.querySelectorAll('.nav-item').forEach(el => el.classList.remove('active')); document.querySelector(`[data-page="${name}"]`).classList.add('active'); }
Dashboard Admin — sw(id) + swTab(prefix, tab, btn)
// sw: switch section chính function sw(id) { SECS.forEach(s => document.getElementById('sec-' + s).style.display = 'none'); document.getElementById('sec-' + id).style.display = 'block'; } // swTab: switch sub-tab bên trong section function swTab(prefix, tab, btnPrefix) { // ẩn tất cả [id^="prefix-"] document.querySelectorAll(`[id^="${prefix}-"]`).forEach(el => el.style.display = 'none'); document.getElementById(`${prefix}-${tab}`).style.display = 'block'; // ⚠ ID con dùng underscore: vt_pending_empty (không phải vt-pending-empty) }

🔀 Demo Toggle Pattern

Mỗi section có thể switch giữa empty state và filled state để demo. Dùng để showcase khi present cho stakeholder.

Demo toggle — HTML + JS chuẩn
<!-- Toggle buttons --> <div class="demo-toggle"> <button onclick="toggleXxx('filled')" id="btnFilled">📊 Có dữ liệu</button> <button onclick="toggleXxx('empty')" id="btnEmpty">🌱 Tài khoản mới</button> </div> <!-- Content divs --> <div id="xxx-filled"> ... existing content ... </div> <div id="xxx-empty" style="display:none"> ... empty state ... </div> // JS function function toggleXxx(state) { document.getElementById('xxx-empty').style.display = state === 'empty' ? 'block' : 'none'; document.getElementById('xxx-filled').style.display = state === 'filled' ? 'block' : 'none'; document.getElementById('btnEmpty').style.background = state === 'empty' ? '#0D2D6B' : 'transparent'; document.getElementById('btnFilled').style.background = state === 'filled' ? '#0D2D6B' : 'transparent'; // swap text color similarly... }
